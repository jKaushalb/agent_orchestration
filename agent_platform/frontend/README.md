# Frontend (React + React Flow)

Separate, self-contained project. Talks to the backend only over REST + SSE.

- Chunk 4: chat bar (live message stream with agent labels, text + image input)
  and agent CRUD forms.
- Chunk 6: React Flow workflow builder (nodes = agents, edges = routes +
  conditions).

```bash
npm install
npm run dev   # http://localhost:5173, proxied to the backend on :8000
```
